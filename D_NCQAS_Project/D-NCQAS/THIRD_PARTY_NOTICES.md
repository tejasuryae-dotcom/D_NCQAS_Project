# Attribution and third-party components

This release revises the user-provided D-NCQAS project. Attribution is retained to
D-NCQAS contributors pending confirmation of the individual author list. The base
research framework is cited as Urbaneja et al., ISC 2026, DOI 10.23919/ISC.2026.11520504.
The implementation is a modified reconstruction, not official source-paper code.

NumPy, SciPy, pandas, Matplotlib, tabulate, PySCF, h5py, and Jupyter components are
external dependencies and retain their respective licenses. No third-party package
source code or journal article PDFs are redistributed in this archive. Generated
Hamiltonian matrices include their PySCF version and complete generation inputs.

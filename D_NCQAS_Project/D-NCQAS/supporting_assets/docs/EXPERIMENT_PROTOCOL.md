# Experimental protocol

The active research protocol is [REVISION_PROTOCOL.md](REVISION_PROTOCOL.md).
It supersedes the version-2 ten-seed/54-test design. Exact phase configurations
are under `configs/`; the frozen final study is `configs/final_study.json`.

The legacy `configs/publication.json` is retained only to reproduce the earlier
algorithm configuration or exercise the original driver. It is not the source
of the revision-3 paper results. The new paper uses the phase runners and analysis
commands in `QUICKSTART.md`. No version-2 result tables are included as new results.
